# Решения по согласованию математической модели

Дата фиксации: 2026-10-24. Версия: `v1`.

| Расхождение | Решение |
|---|---|
| Старые пороги PD 5%/15% против Go 10%/25% | Каноничны 10%/25% из продуктовых политик миграции `000002`; правила не менялись ради распределения решений. |
| Четырёхфакторная карта ноутбука против восьмифакторной карты БД | Канонична версионированная карта `v1` из `000004`; старые CSV отсутствуют и не восстанавливаются вымышленными числами. |
| `WORKING_CAP`, `EQUIPMENT`, `CASH_GAP` | Каноничны API-коды `WORKING_CAPITAL`, `INVESTMENT_LOAN`, `OVERDRAFT`. |
| Формула `r*` без LGD | Используется `(r₀ + PD×LGD)/(1−PD)` из Go и продуктовой схемы. |
| PGap без `C₀` в Go | Исправлено: используется `C₀/n` в аналитике, лимитах и офферах. |
| `σ = μ×industry_cv` против фактических 12 месяцев | Канонично `σ = std(monthly_revenue, ddof=0)×margin`; industry CV применяется только при синтетическом расширении, когда истории нет. |
| Эталонные персоны не совпадали с demo-users | Golden CSV генерируется из `ml/app/companies.json` и десяти `client1`…`client10`. |

Источники истины по приоритету: миграции параметров → Go-код →
`ml/app/model.py` → документация и ноутбуки. Cross-language golden-тест не
пропускается при отсутствии CSV и сравнивает численные результаты.
