# Шаблоны фраз и правила генерации объяснений (`phrase_templates.csv`)

Данный документ описывает логику автоматического формирования человекопонятных объяснений кредитного решения для интерфейса предпринимателя (Задача 7). 

Чтобы исключить необходимость ручного программирования текстовых условий на стороне Go-бэкенда, файл `phrase_templates.csv` использует **ту же структуру интервалов (`lower`, `upper`, `category`)**, что и скоринговая карта `scorecard_bins.csv`.

---

## 1. Правила чтения таблицы для Backend-сервиса (Go)

1. **Выбор итогового вердикта (`template_type == 'verdict'`):**
   Бэкенд выбирает строку, где поле `status` совпадает с рассчитанным статусом заявки (`APPROVED`, `APPROVED_WITH_CHANGES` или `REJECTED`), и подставляет в `client_text` расчетные параметры сделки.
2. **Выбор объяснений по факторам (`template_type == 'factor'`):**
   Для каждого из 4 входных факторов (`business_age_months`, `debt_burden_ratio`, `has_delinquency`, `business_type`) применяется единое правило сопоставления:
   * Для числовых факторов: **`lower < x <= upper`** (пустое значение означает бесконечность).
   * Для категориальных факторов: точное совпадение со значением в колонке **`category`**.
3. **Принцип прозрачности без банковского жаргона:**
   В клиентские тексты (`title`, `client_text`) не выводятся внутренние скоринговые баллы (`points`) и технические вероятности (`PD`), чтобы предприниматель получал понятную обратную связь на языке бизнеса.

## 2. Таблица шаблонов итогового решения (`template_type = verdict`)

| status | tone | Заголовок (`title`) | Шаблон текста для клиента (`client_text`) |
| :--- | :--- | :--- | :--- |
| `APPROVED` | `positive` | Заявка одобрена на ваших условиях | Мы готовы предоставить финансирование в размере `{offer_amount}` ₽ на срок `{offer_term}` мес. под ставку `{rate_pct}`% годовых. Ежемесячный платеж составит `{payment}` ₽ — он полностью комфортен для вашего текущего оборота. |
| `APPROVED_WITH_CHANGES` | `warning` | Одобрено специальное предложение с защитой от кассового разрыва | При запрошенных параметрах (`{amount}` ₽ на `{term_months}` мес.) ежемесячный платеж создал бы высокую нагрузку на оборотные средства в месяцы сезонного спада выручки. Чтобы кредит был безопасен для бизнеса, мы предлагаем `{offer_amount}` ₽ на срок `{offer_term}` мес. под ставку `{rate_pct}`% годовых (комфортный платеж `{payment}` ₽/мес.). |
| `REJECTED` | `negative` | К сожалению, сейчас мы не можем одобрить беззалоговый кредит | По результатам оценки дополнительный кредит сейчас создаст избыточную финансовую нагрузку на ваш бизнес. Рекомендуем снизить платежи по действующим обязательствам до уровня менее 30–40% от прибыли или рассмотреть продукты под залог. |
