# Математические формулы кредитного конвейера (Задачи 2–4)

## 1. Фактор долговой нагрузки (`debt_load`) для скоринговой карты

В качестве знаменателя используется среднемесячный операционный денежный поток `μ` (прибыль до вычета текущих кредитных платежей), что делает пороги карты (`0.30` и `0.60`) универсальными для отраслей с разной рентабельностью:

> **μ = Revenue_month × margin**
>
> **debt_load = D_old / μ**

*Где:*
* `Revenue_month` — среднемесячная выручка клиента (руб.).
* `margin` — рентабельность отрасли из `industry_params.csv` (в долях).
* `D_old` — сумма ежемесячных платежей по действующим обязательствам клиента (руб.).

---

## 2. Базовая ставка `r_0`, равновесная ставка `r*` и платеж (для `scoring/rate.go`)

**1. Базовая ставка по кредитному продукту (`r_0`):**
> **r_0 = KEY_RATE + m_prod**

*Где:*
* `KEY_RATE` — ключевая ставка ЦБ РФ (в долях).
* `m_prod` — базовая маржа конкретного кредитного продукта (в долях).

**2. Равновесная годовая ставка с учетом риска дефолта (`r*`):**
Выводится из уравнения безубыточности ожидаемой доходности банка `(1 − PD_client) × (1 + r*) = 1 + r_0`:

> **r_star = (r_0 + PD_client) / (1 − PD_client)**

*(Вариант с учетом уровня потерь при дефолте `LGD` от 0 до 1: **`r_star = (r_0 + PD_client × LGD) / (1 − PD_client)`**).*

**3. Месячная ставка и аннуитетный платеж (`payment`):**
> **r_m = r_star / 12**
>
> **payment = amount × [ (r_m × (1 + r_m)^n) / ((1 + r_m)^n − 1) ]**

*Где:*
* `amount` — сумма кредита (руб.).
* `n` — срок кредита в месяцах (`term_months`).

## 3. Вероятность кассового разрыва `P_gap` с учетом подушки `C_0` (для `scoring/cashgap.go`)

Операционный поток моделируется нормальным распределением `N(μ, σ²)`. Кассовый разрыв возникает, когда ежемесячный платеж по новому кредиту превышает свободный денежный поток клиента, подкрепленный подушкой остатка на расчетном счете `C_0`.

**1. Параметры распределения операционного потока:**
> **μ = Revenue_month × margin**
>
> **σ = μ × revenue_cv**

*Где:* `revenue_cv` — коэффициент вариации выручки отрасли из `industry_params.csv`.

**2. Доступный месячный денежный поток с учетом подушки остатка на счете (`C_0`):**
* Вариант А (при распределении подушки `C_0` на весь срок кредита `n` месяцев):
  > **Available_Cash = μ − D_old + (C_0 / n)**
* Вариант Б (при оценке риска кассового разрыва на горизонте одного месяца без учета `n`):
  > **Available_Cash = μ − D_old + C_0**

**3. Квантиль нормального распределения (`Z`-оценка):**
> **Z = (payment − Available_Cash) / σ**

**4. Вероятность кассового разрыва (`P_gap`) через функцию ошибок Гаусса:**
> **P_gap = Φ(Z) = 0.5 × [ 1 + erf( Z / √2 ) ]**

**Определение функции ошибок Гаусса $\text{erf}(x)$ через интеграл:**

$$\text{erf}(x) = \frac{2}{\sqrt{\pi}} \int_{0}^{x} e^{-t^2} \, dt$$

**Численное вычисление $\text{erf}(x)$ через разложение в ряд Тейлора:**

$$\text{erf}(x) = \frac{2}{\sqrt{\pi}} \sum_{n=0}^{\infty} \frac{(-1)^n x^{2n+1}}{n! (2n+1)} \approx \frac{2}{\sqrt{\pi}} \left( x - \frac{x^3}{3} + \frac{x^5}{10} - \frac{x^7}{42} + \frac{x^9}{216} - \dots \right)$$

## 4. Точки А и Б: Пороги отсечения и формула альтернативного оффера

Пороговые значения:
* **Точка А (граница Зеленой зоны):** `PD_A = 0.05`, `P_gap_max = 0.25`.
* **Точка Б (граница Красной зоны / Стоп-фактор):** `PD_B = 0.15`.

**Правила классификации:**

1. **`APPROVED` (Зеленая зона):** `PD_client < PD_A` **И** `P_gap < P_gap_max`
   > **offer_amount = amount**
   >
   > **offer_term = n**

2. **`REJECTED` (Красная зона):** `PD_client >= PD_B`
   > **offer_amount = 0, offer_term = 0, r_star = 0, payment = 0**

3. **`APPROVED_WITH_CHANGES` (Желтая зона — переход из Точки А в Точку Б):** `PD_client < PD_B`, но (`P_gap >= P_gap_max` **ИЛИ** `PD_client >= PD_A`)
   * Новый срок кредита:
     > **offer_term = min(n + 12, 60)**
   * Безопасный ежемесячный платеж (при котором `P_gap <= P_gap_max`, где квантиль `Z_max = -0.6745` для порога 25%):
     > **safe_payment = Available_Cash + (Z_max × σ)**
     *(Либо упрощенно через фиксированную долю свободного потока: **`safe_payment = 0.70 × Available_Cash`**).*
   * Максимальная безопасная сумма кредита (обратная формула аннуитета):
     > **max_safe_amount = safe_payment × [ ((1 + r_m)^offer_term − 1) / (r_m × (1 + r_m)^offer_term) ]**
   * Итоговая предлагаемая сумма:
     > **offer_amount = min(amount, max_safe_amount)**
